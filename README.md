# 1. Descripción del proyecto
THD-Factoy es una empresa ficticia especializada en la consultoría e integración de Tecnologías Habilitadoras Digitales (THD)

Este proyecto consiste en el diseño y desarrollo de una página web con el objetivo de ayudar a los negocios a digitalizar sus procesos, en este caso nos orientamos en el sector de la hostelería y la restauración. 

A través de este proyecto esetudiamos diferentes tecnologías digitales, sus aplicaciones en el sector productivo y las oportunidades de negocio que pueden generar.

# 2. Objetivos
- Identificar y explicar las diferentes THD.
- Relacionar las tecnologías con productos y servicios.
- Analizar cómo contribuyen en la sostenibilidad.
- Identificar nuevos mercados y oportunidades de negocio.
- Diferenciar entornos IT y OT.
- Mejoría de funcionamiento de empresa gracias a las THD.

# 3. Contenido de la página web
Se organiza en seis páginas principales:
- Index, que describe la empresa, valores y tecnologías que trabaja.
- Catalogo, muestra las diferentes THD y servicios ofrecidos.
- Sostenibilidad, breve descripción de tecnologías sostenibles.
- Mercados, nuevvos mercados y oportunidades generadas.
- IT-OT, difernecias entre IT y OT y convergencia.
- Informe, informe técnico y conclusiones.

# 4. Tecnologías estudiadas
- Cloud Computing: almacenamiento y acceso a información mediante servicios en la nube.
- Inteligencia Artificial y Machine Learning: análisis de datos y predicción de la demanda.
- Internet de las Cosas (IoT): conexión de dispositivos y sensores para obtener información en tiempo real.
- Ciberseguridad: protección de sistemas, dispositivos y datos.
- Big Data y Data Analytics: recopilación y análisis de grandes cantidades de información.
- Gemelo digital: representación virtual de un entorno o proceso físico.
- Biotecnología industrial: aplicación de procesos biológicos en actividades productivas y sostenibles.
