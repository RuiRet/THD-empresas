# 1. Descripción del proyecto
TurisNex es una empresa ficticia especializada en la consultoría e integración de Tecnologías Habilitadoras Digitales (THD)

Este proyecto consiste en el diseño y desarrollo de una página web con el objetivo de ayudar a los negocios a digitalizar sus procesos, en este caso nos orientamos en el sector de la hostelería y la restauración. 

A través de este proyecto esetudiamos diferentes tecnologías digitales, sus aplicaciones en el sector productivo y las oportunidades de negocio que pueden generar.

# 2. Objetivos
- Identificar y explicar las diferentes THD.
- Relacionar las tecnologías con productos y servicios.
- Analizar cómo contribuyen en la sostenibilidad.
- Identificar nuevos mercados y oportunidades de negocio.
- Diferenciar entornos IT y OT.
- Mejoría de funcionamiento de empresa gracias a las THD.

# 3. Contenido de la página web
Se organiza en seis páginas principales:
- Index, que describe la empresa, valores y tecnologías que trabaja.
- Catalogo, muestra las diferentes THD y servicios ofrecidos.
- Sostenibilidad, breve descripción de tecnologías sostenibles.
- Mercados, nuevvos mercados y oportunidades generadas.
- IT-OT, difernecias entre IT y OT y convergencia.
- Informe, informe técnico y conclusiones.

# 4. Tecnologías estudiadas
- Cloud Computing: almacenamiento y acceso a información mediante servicios en la nube.
- Inteligencia Artificial y Machine Learning: análisis de datos y predicción de la demanda.
- Internet de las Cosas (IoT): conexión de dispositivos y sensores para obtener información en tiempo real.
- Ciberseguridad: protección de sistemas, dispositivos y datos.
- Big Data y Data Analytics: recopilación y análisis de grandes cantidades de información.
- Gemelo digital: representación virtual de un entorno o proceso físico.
- Biotecnología industrial: aplicación de procesos biológicos en actividades productivas y sostenibles.

# 1. PLANIFICACIÓN GENERAL

## Concepto de la empresa

Crear una empresa ficticia de consultoría e integración de tecnologías habilitadoras digitales (THD), especializada en la transformación digital de restaurantes.

Su objetivo será ofrecer soluciones tecnológicas que permitan:
- Digitalizar la gestión de reservas, pedidos, compras e inventario.
- Automatizar procesos y reducir errores.
- Analizar los datos para mejorar la rentabilidad.
- Controlar el consumo energético y reducir desperdicios.
- Mejorar la seguridad de la información.

El Restaurante El Boquerón será el cliente utilizado como referencia para explicar las soluciones y desarrollar el caso de éxito.

## Tecnologías que se desarrollarán

| Tecnología | Aplicación principal |
|---|---|
| Cloud Computing | Centralización de información. |
| Inteligencia Artificial y Machine Learning | Predicción de demanda y planificación. |
| Internet de las Cosas (IoT) | Sensores de temperatura, ocupación y energía. |
| Ciberseguridad | Protección de datos y sistemas. |
| Big Data y analítica | Análisis de ventas y rentabilidad. |
| Gemelo digital | Simulación del funcionamiento del restaurante. |
| Biotecnología industrial | Aprovechamiento de residuos orgánicos y materiales biológicos. |

Las seis primeras tecnologías constituyen el catálogo principal y la biotecnología industrial será la tecnología emergente.

# 3. RECOMENDACIONES PARA EL DISEÑO HTML

La práctica prohíbe expresamente utilizar CSS y JavaScript. Por tanto, toda la estructura visual debe realizarse mediante HTML.

## Elementos HTML recomendados

| Etiqueta | Utilización |
|---|---|
| `<header>` | Cabecera de cada página. |
| `<nav>` | Menú de navegación. |
| `<main>` | Contenido principal. |
| `<section>` | Separar apartados. |
| `<article>` | Fichas de tecnologías. |
| `<h1>` – `<h3>` | Títulos y subtítulos. |
| `<p>` | Párrafos. |
| `<ul>` / `<ol>` | Listas. |
| `<table>` | Tablas comparativas. |
| `<img>` | Imágenes. |
| `<a>` | Enlaces internos y externos. |
| `<footer>` | Pie de página. |
| `<form>` | Formulario de contacto. |

## Estructura recomendada para todas las páginas

Todas las páginas deberían compartir:

1. Cabecera con logotipo y nombre de la empresa.
2. Menú de navegación con enlaces a las seis páginas.
3. Título principal.
4. Introducción al contenido.
5. Apartados correspondientes.
6. Pie de página con información de la empresa y enlaces.

## Menú de navegación

Debe aparecer en las seis páginas y permitir acceder a todas ellas.

Los enlaces deben utilizar rutas relativas:

- `index.html`
- `catalogo.html`
- `sostenibilidad.html`
- `mercados.html`
- `it-ot.html`
- `informe.html`

## Imágenes

Guardar las imágenes en una carpeta `img/`.

Utilizar rutas relativas y añadir siempre el atributo `alt` para describirlas.
